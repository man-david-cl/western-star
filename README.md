# WESTERN STAR — Merchandise Capital Portfolio

Phase 1 responsive Next.js client dashboard prototype.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Important
This is a frontend prototype only. It does not yet include authentication, database persistence, server-side authorization, audit logging, payment processing, or secure document storage. Do not use real client financial data in a public deployment until those protections are implemented.

The Phase 1 source archive will be added to this repository.
